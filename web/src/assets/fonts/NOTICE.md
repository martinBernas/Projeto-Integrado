# Ubuntu font

Ubuntu-R.ttf is the unmodified Ubuntu Regular font distributed with the local Poppler runtime. Copyright 2011 Canonical Ltd. Font metadata retains its copyright and original name. Licensed under the Ubuntu Font Licence 1.0, reproduced in UFL.txt.

License source: https://github.com/google/fonts/blob/main/ufl/ubuntu/UFL.txt

The font is embedded in tournament PDFs for Portuguese accents and supported Unicode characters. It is not used as a remote web font.
